## Notes

- PSP renders: Phobos's headless PSP runner (tools/psp-runner) built from commit b14ef87a0, the PSP emulation code master has carried since #291, each scene started from a saved state and drawn by the Vulkan (fast) renderer at 4x internal resolution (read back at 1920x1088) on Linux, an AMD Radeon RX 9070 XT on Mesa's RADV driver. Clips: every frame captured, encoded at 60 frames a second, so a game that draws 30 frames a second shows each twice. Each PSP still and clip was measured for real 4x detail. On a still's lossless frame: the share of colour edges that fall on the 4-pixel grid, about 25% for a real 4x frame (which is chance) and 100% for one drawn at the PSP's 480x272 and shown 4 times larger, and the share of 4x4 blocks with detail inside. On a clip: the same edge share on its master's luma, every frame. A loaded scene's first frame comes from memory at native size and is never used.
